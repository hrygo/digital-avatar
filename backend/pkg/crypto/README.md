# 基于NLP的PII检测和替换系统

## 概述

本项目实现了一个基于自然语言处理（NLP）技术的敏感信息（PII）检测和替换系统，取代了原有的正则表达式方案。该系统能够更准确地检测和替换各种类型的敏感信息。

## 系统架构

### 核心组件

1. **NLPPIIDetector** - 主要的检测器类
2. **词典系统** - 姓名词典、姓氏词典、公司后缀、地理位置后缀
3. **模式匹配器** - 用于明确的PII类型（电话、邮箱、身份证）
4. **上下文分析器** - 基于上下文的置信度计算
5. **一致性替换系统** - 基于哈希的一致性匿名化

## 支持的PII类型

| 类型 | 代码 | 描述 | 检测方法 | 替换模式 |
|------|------|------|----------|----------|
| 人名 | PER | 中文姓名 | 词典+上下文+置信度 | `[姓名hash]` |
| 组织机构 | ORG | 公司、机构 | 后缀匹配+置信度 | `[公司hash]` |
| 地理位置 | LOC | 省、市、区等 | 后缀匹配+置信度 | `[地址]` |
| 电话号码 | TEL | 手机、固话 | 正则表达式 | `[手机号码]` |
| 邮箱地址 | EMAIL | 电子邮箱 | 正则表达式 | `[邮箱地址]` |
| 身份证号 | ID | 身份证号码 | 正则表达式 | `[身份证号]` |
| 地址 | ADDR | 详细地址 | 复合匹配 | `[地址]` |

## 主要特性

### 1. 多层次检测策略
- **模式匹配**：处理明确的格式化PII（电话、邮箱、身份证）
- **词典匹配**：处理中文名字、姓氏、常见词汇
- **后缀匹配**：处理组织机构和地理位置
- **上下文分析**：基于前后文提高检测准确性

### 2. 智能置信度计算
- **基础分数**：根据检测类型赋予基础分数
- **长度验证**：检查文本长度是否符合特征
- **上下文加分**：基于前后文词汇调整置信度
- **排除规则**：过滤明显的误匹配

### 3. 一致性匿名化
- **哈希映射**：相同实体使用相同的匿名化标识
- **类型区分**：不同PII类型使用不同的替换模式
- **全局一致**：同一实体在不同文本中保持一致

### 4. 性能优化
- **并发安全**：使用读写锁保护共享状态
- **内存高效**：避免重复计算和存储
- **快速匹配**：优化正则表达式和字符串操作

## 使用示例

```go
package main

import (
    "fmt"
    "twin-os/backend/pkg/crypto"
)

func main() {
    // 创建检测器
    detector := crypto.NewNLPPIIDetector()

    // 检测并替换PII
    text := "我的名字是张三，电话是13812345678，在腾讯有限公司工作。"
    processed, entities := detector.DetectAndReplace(text, 0.6)

    fmt.Printf("原文: %s\n", text)
    fmt.Printf("处理后: %s\n", processed)
    fmt.Printf("检测到 %d 个敏感信息\n", len(entities))

    for i, entity := range entities {
        fmt.Printf("  %d. %s (%s) -> %s (置信度: %.2f)\n",
            i+1, entity.Text, entity.Type, entity.Replaced, entity.Score)
    }
}
```
