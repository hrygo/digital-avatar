## 🔧 技术架构优化

### 前端架构 (端口: 3000)
```
React 18 + TypeScript
├── 状态管理: Zustand
├── UI框架: TailwindCSS + Framer Motion
├── 通信: Axios + REST API
└── 桌面化: Electron
```

### 后端架构 (端口: 1234)
```
Go 1.21 + Gin
├── 数据库: SQLite + AES加密
├── AI集成: DeepSeek API
├── 安全: PII脱敏 + 本地处理
└── API: RESTful + JSON
```

### 通信协议
- **开发环境**: HTTP (localhost)
- **端口分配**: 1234(后端), 3000(前端)
- **数据格式**: JSON
- **认证方式**: 本地密钥验证
