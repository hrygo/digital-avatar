## 🛑 归档说明 (2025/11/20)
由于无法在不违反服务条款或使用不稳定手段的情况下读取真实的微信本地数据库（EnMicroMsg.db），项目组决定终止以微信数据集成（v0.4.0）为核心的产品演进方向。

所有代码和文档将封存，以供未来参考或在技术条件允许时重启。

### ❌ v0.4.0 - 微信数据集成版 (已取消)
**终止日期**: 2025-11-20

#### 终止原因
- 无法通过合法/稳定途径访问微信本地数据库。
- 技术调研表明，绕过微信的安全机制将带来极高的维护成本和法律风险。

#### 已完成工作 (封存)
- 微信数据导入前端向导 (React)
- 基础的数据库解析器结构 (Go)
- API 接口定义
