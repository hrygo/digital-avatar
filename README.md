# 🧠 TwinOS - 智能决策副驾系统

> **"你就负责思考，剩下的交给它。"**

## 📋 项目概述

TwinOS 是面向高净值人群和商业精英的 **"极致效率型数字分身"** 系统。它不是简单的聊天机器人，而是用户的 **"第二大脑"** 和 **"认知外接器官"**，通过深度信息处理和智能分析，为用户提供决策支持和效率提升。

## 🎯 核心价值主张

### 用户痛点解决
- ❌ **信息过载** → ✅ **智能降噪，只留信号**
- ❌ **时间稀缺** → ✅ **自动化处理，节省时间**
- ❌ **决策困难** → ✅ **数据驱动，智能建议**
- ❌ **关系维护难** → ✅ **人脉雷达，主动提醒**

### 核心功能
- 📊 **今日情报简报**: AI生成的300字摘要，概括关键信息
- 📋 **决策待办**: 自动识别高优先级事项，避免遗漏
- 🎯 **人脉雷达**: 谁在谈论你？谁提及了关键项目？
- 🔒 **隐私保护**: 本地处理，端到端加密，数据永不上云

## 🏗️ 技术架构

### 技术栈
- **前端**: Electron + React + TypeScript + TailwindCSS
- **后端**: Go 1.21+ + Gin + GORM
- **AI**: DeepSeek API + 自定义Prompt工程
- **数据库**: SQLite (本地) + Redis (缓存)
- **安全**: AES-256-GCM + 多层加密保护

### 系统架构
```
感知层 → 认知层 → 决策层 → 执行层 → 基础层
  ↓        ↓        ↓        ↓        ↓
数据采集 → AI分析 → 策略生成 → 任务执行 → 安全存储
```

## 🚀 快速开始

### 环境要求
- **Go**: 1.21+
- **Node.js**: 18+
- **Python**: 3.8+ (用于AI开发)
- **Git**: 最新版本

### 安装步骤

1. **克隆项目**
```bash
git clone https://github.com/your-org/twinos.git
cd twinos
```

2. **后端设置**
```bash
cd backend
go mod download
go run cmd/server/main.go
```

3. **前端设置**
```bash
cd frontend
npm install
npm run dev
```

4. **配置环境变量**
```bash
# 复制环境变量模板
cp .env.example .env

# 编辑配置文件
vim .env
```
